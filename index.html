Click the dot to cycle status (todo → working on → done). Click a task to edit it (set High/Med/Low priority there — a red, amber, or blue left stripe marks High/Med/Low and higher-priority tasks rise to the top of each category), or a category name to rename. Drag tasks between categories, or drag the grip in a category header to reorder categories. Recurring tasks repeat each week with a fresh todo — uncheck "Repeats weekly" or use the delete dialog to stop. Random stays by default (even when empty) but can be deleted like any category; other empty categories drop off when the week rolls over. Ctrl+Z / Ctrl+Y to undo / redo.
